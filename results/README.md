# results

Raw results and their metadata. Generated by the harness, never edited by
hand. `REPORT.md` and `docs/feature-matrix.md` are generated from this tree.

| Path | Contents | Written by |
| --- | --- | --- |
| `<workload>/<scenario>/<platform>/<tier>/<run-id>/` | `run.json` (timings, CPU, value digests, seed, migrations), `report.md`, `metadata.json` (server version, settings, topology, disks, caches, drift) | `bench --target …` |
| `<workload>/<scenario>/<platform>/<tier>/cogs/` | COGS runs | `bench cogs` |
| `parity/` | Cross-target parity reports (`bench compare` output per scenario) | `scripts/local-parity.sh` |
| `probes/<platform>/<tier>/<run-id>/` | Probe outcomes and target metadata | `bench probe` |
| `consistency/<platform>/<tier>/<run-id>/` | Replica-consistency runs per policy (D7) | `bench consistency` |
| `experiments/<id>/<platform>/<tier>/<run-id>/` | Local correctness experiments S3, S4, R3, R6 and E5, E6 (D13, D15) | `bench experiment`, `experiments/kind/e5-e6.sh` |

The `<tier>` directory is the manifest file name, for example
`local-cluster-2x2`.

**Local tiers** (`local-single`, `local-cluster*`, `kind`):
- They back correctness, parity, capability and behaviour checks only.
- Their timings come from a shared sandbox and are not evidence about any
  platform's performance or cost (ADR-0005).
- Run records carry `smoke_only: true`.

**Reproducibility:**
- Every record carries the harness commit.
- Evidence runs are made from a clean checkout. A `-dirty` commit marks a run
  that cannot be reproduced from its commit alone.
