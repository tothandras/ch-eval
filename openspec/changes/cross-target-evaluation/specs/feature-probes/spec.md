## ADDED Requirements

### Requirement: Executable probes per feature-matrix row
Every row of `docs/feature-matrix.yaml` SHALL reference at least one primary-source citation (ClickHouse docs, Altinity docs or repositories, or release notes and changelogs) and either a probe in the repo (an SQL file with an `expect:` header, or a Go test) or an explicit `assessed: true` flag with justification. `bench probe --target X` SHALL run all probes and record outcome, error code, and the live `version()` per probe.

#### Scenario: Restricted statement on Cloud
- **WHEN** a probe expecting `error:<code>` on cloud and `ok` on self-managed runs on both
- **THEN** the probe result records PASS on each target, and records FAIL with the observed outcome if behaviour differs from the expectation

### Requirement: Generated feature matrix
`docs/feature-matrix.md` SHALL be generated by `bench feature-matrix` from the YAML rows and the latest probe results per target, showing each cell's probed status with the exact server version. Unprobed cells SHALL carry an explicit hypothesis marker.

#### Scenario: Unprobed cell
- **WHEN** a row's probe has not run on `cloud`
- **THEN** the cloud cell shows the sourced hypothesis with the hypothesis marker, not a probed status
